# 误差与验收

体积误差不能只报一个「2%」，要能回答「误差从哪来」。本文给出误差链、验收口径与验证方法。

## 1 误差链

```
标定重投影误差 → 相位/视差误差 → 三维点误差 → 等值面表面位置误差 δ → 符号体积积分误差
```

对水密闭合网格，由散度定理可得一阶近似：

```
ΔV / V ≈ S·δ / V ≈ 3δ / R
```

其中 S 为表面积、R 为等效半径。取 δ = 0.42 mm、R = 5 cm：

```
ΔV/V ≈ 3 × 0.42 / 50 = 2.5%
```

这条式子取代了原来「1 mm 轮廓误差约对应 6% 体积」的经验估算，并解释了为什么 δ 是真正的瓶颈——不是体素尺寸，也不是算法选择。

δ 敏感性：

| δ (mm) | R = 5 cm 时 ΔV/V | R = 10 cm 时 ΔV/V |
|---|---|---|
| 0.30 | 1.8% | 0.9% |
| 0.42 | 2.5% | 1.3% |
| 0.60 | 3.6% | 1.8% |
| 0.80 | 4.8% | 2.4% |

因此对外承诺不依赖 δ 的最终实测值：即使 δ 上浮到 0.6 mm，仍在 5% 以内。δ = 0.42 mm 是过程控制用的内部目标，不是承诺边界。

## 2 设计目标与承诺边界

| 口径 | 数值 | 性质 |
|---|---|---|
| 类Ⅰ 设计目标 | 0.1–0.3% | 基元解析的理论上限，待实测 |
| 类Ⅱ 设计目标 | 0.3–1% | 待实测 |
| 类Ⅲ 设计目标 | ≤0.3% | 限纹理充分、视角完整、无强遮挡 |
| 系统内部目标 | <2% | 已含 unknown 域与补全区误差 |
| 对外承诺 | <5% | 承诺边界 |

设计目标与承诺边界不可并列当作既成指标；类Ⅰ 的低误差只在「轮廓由拟合参数给出、不依赖逐点重建」时成立，不能当作全系统承诺。

## 3 四项验收

| 项 | 内容 | 门限 |
|---|---|---|
| ① 形状误差 | 点云/网格对 CMM 参考模型的 RMS（最小二乘配准后） | ≤0.5 mm（约 1.2δ） |
| ② 全量程分档 | 50–200 / 200–1000 / 1000–2000 cm³ 三档相对误差 | 各档 P95 ≤ 承诺 |
| ③ 时序稳定性 | 连续 20 件单件用时 P95 | <55 s |
| ④ 结果口径 | 每件输出 V ± U（k=2） | U = 2u_c |

u_c 由四项按 GUM 方和根合成：表面点定位（3δ/R）、体素量化、配准残差、unknown 域补全。

注：门限 0.5 mm 低于 δ 会与该误差预算互斥，取 1.2δ 是刻意的——它衡量的是「形状是否对」，不是「精度是否达 δ」。

## 4 验证件分级

| 类型 | 真值来源 | 用途 | 数量 |
|---|---|---|---|
| 溯源基准件 | CMM 标定（量块/标准球） | 每日健康检查 | ≥3 |
| 类Ⅰ 验证件 | CMM 或精密量具 | 解析法精度 | ≥5 |
| 类Ⅱ 验证件 | CMM | 积分精度 | ≥5 |
| 类Ⅲ 验证件 | CMM 为主；开放通孔可排水法交叉 | 封口剔除精度 | ≥5 |
| 薄壁/细孔专项 | CMM 测厚 | 壁厚门槛与细化效果 | ≥5 |

排水法不能当盲孔真值：困气会让排水体积偏大。

## 5 姿态与薄壁的专项验证

- **姿态度验证**：类Ⅱ/类Ⅲ 同一件按平放、侧放、倒扣三种姿态各测 5 次，统计姿态间最大偏差，不得超同档承诺。超限须回溯体素分辨率、unknown 分治与位姿标定，不能只对单一姿态调参。
- **薄壁专项**：壁厚 1–3 mm 板材与细孔件单独成组，除体积误差外另报厚度方向误差（均值与最大偏差），不计入 ① 的全件 RMS。

## 6 已知空白

以下六项尚无实测数据，是当前最脆弱的环节：

1. δ 的分项拆解（标定/相位/量化各占多少）；
2. 编码档位定档（7 幅还是 13 幅）；
3. 85% 调制率初值；
4. 3 mm 壁厚门槛与 0.3 mm 细化的实际效果；
5. 姿态间最大偏差门限；
6. 类Ⅱ/类Ⅲ 设计目标的实测支撑。

在补齐之前，`docs/01` 与 `docs/02` 中的精度数字只能作为设计意图阅读。
