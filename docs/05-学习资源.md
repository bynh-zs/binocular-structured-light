# 学习资源

结构光方向的自学路径与外部资源索引。所有链接指向第三方公开内容，版权归原作者；本仓库只做索引，不转载。

## 建议顺序

1. **建立概念分界**（30 分钟）：先弄清三角法、相位法、编码法各解决什么问题，再看长课。
2. **跑通全链路**（半天）：跟着一条含源码的系统课，边看边复现，不要一次刷完再动手。
3. **吃透编码**（半天）：格雷码 + 相移的组合、幅数压缩、误码为何是整级跳变。
4. **标定**（2 小时）：相机内参、双目标定、相机-投影标定，误差链源头。
5. **专题**（按需）：多频外差解包裹、散斑匹配、点云配准。

## 三个甄别提醒

1. **「光栅」是歧义词**。中文语境下大量结果是光栅尺、光栅传感器、安全光栅、打印机光栅条，与结构光无关。检索用「结构光」「面结构光」「相移」。
2. **单目教程远多于双目**。相位到深度这一段通用，但双目多出极线校正、左右一致性检查与同步触发三件事。
3. **面结构光 ≠ 线结构光**。后者是线激光逐线扫描，编码、采集、时序都不同，不能照搬。
